Speedy iRepair — Widget Test

Chat-first widget with voice fallback. Click the floating chat button bottom-right.

What to expect — Chat mode (default):
  • Click the blue/purple round button (bottom-right) → panel opens
  • Jess greets: "Hey — Jess from Speedy iRepair. What's going on with the phone?"
  • Type: "My iPhone 13 screen is cracked" → Jess quotes a range, asks to book
  • Reply "yes, today" → Jess pulls live slots from Square sandbox, reads 2 back
  • Pick a time + give name + phone → booking lands in Square sandbox
What to expect — Voice mode:
  • Tap Call button in the panel header (top-right)
  • Browser asks for microphone permission — allow it
  • Card switches to "Connected" — talk naturally, same Jess
  • Tap Hang up to end → returns to chat

How to run this locally

cd shop-repain-client/dashboard/widget
python3 -m http.server 8080
# then open http://localhost:8080/test.html

Don't open this file directly via file:// — browsers block microphone access without HTTPS or localhost.

Production embed

Once we deploy widget.js to a public URL (e.g., https://dashboard.speedyirepair.com/widget.js), the owner adds this single line to speedyirepair.com:

<script src="https://dashboard.speedyirepair.com/widget/widget.js" defer></script>
